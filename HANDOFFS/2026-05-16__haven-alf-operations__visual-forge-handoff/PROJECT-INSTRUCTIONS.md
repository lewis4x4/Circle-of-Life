# Haven ALF Operations — Quiet Operator

This file is the binding context for code-agent sessions on Haven ALF Operations.

## Hard rules

1. The design system in `/design-system/` is the law. Read every file in order before writing code.
2. The reference DNA mix is your direction, not your output. Do not clone the references.
3. Tokens are consumed via CSS variables and the Tailwind theme extension. Do not hard-code colors.
4. Every surface must pass `/design-system/acceptance-checklist.md` before you call it done.
5. If a decision is not covered by the system, pause and surface it. Do not improvise.

## Anti-patterns — never ship any of these

- Glassmorphism
- Purple-to-orange gradient
- AI-sparkle / magic-wand iconography
- Bouncy spring animations
- Stock photography of handshakes
- Lottie animations
- Toast notifications for non-critical events
- Stock illustration with characters
- Linear-clone visuals
- Material Design
- Inter font on white
- Pill badges in primary colors
- Bento grid hero
- Decorative gradient borders
- Floating-card soft-shadow layouts
- Generic SaaS template
