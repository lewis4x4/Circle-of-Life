# Visual Direction — Quiet Operator
## Project
**Haven ALF Operations** — Operations platform.
Gives assisted living operators a single source of truth for residents, staff, and families — so executive directors run their building from one screen instead of seven tools.
## Reference DNA
| Reference | Global weight | Use for |
| --- | --- | --- |
| Mercury | 18% | balance-and-value-dashboards, transaction-lists |
| Stripe | 18% | operational-trust-financial-grade-reliability, tables-with-filters-and-pagination |
| Linear | 14% | issue-lists, inboxes |
## Tone profile
Primary tone: **clinical**
Secondary tone: **warm**
## Density
operational — calibrated row heights, padding, and typography per surface.
## Theme
split — chosen to match audience and consequence.
## Consequence profile
Handles: life-safety, legal-exposure, revenue, compliance, reputation, productivity
Severity: 5/5
Who is under pressure: Caregivers on overnight shift, 2-3 staff for 60+ residents, no backup support
The stressful moment: 3am resident fall. CNA must assess, document with timestamps for state survey, notify on-call nurse, and reach family before they hear it elsewhere — while still covering 29 other residents.
