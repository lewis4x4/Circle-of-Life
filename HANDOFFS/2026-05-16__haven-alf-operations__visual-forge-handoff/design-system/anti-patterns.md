# Anti-Patterns

The following are forbidden in Haven ALF Operations. Any of these appearing in a built screen is a failure.

## Curated anti-patterns

- Glassmorphism
- Purple-to-orange gradient
- AI-sparkle / magic-wand iconography
- Bouncy spring animations
- Stock photography of handshakes
- Lottie animations
- Toast notifications for non-critical events
- Stock illustration with characters
- Linear-clone visuals
- Material Design
- Inter font on white
- Pill badges in primary colors
- Bento grid hero
- Decorative gradient borders
- Floating-card soft-shadow layouts
- Generic SaaS template

## Project-specific anti-patterns

- Purple-to-orange gradient
- AI-sparkle / magic-wand iconography
- Bouncy spring animations
- Stock photography of handshakes
- Lottie animations
- Toast notifications for non-critical events
- Stock illustration with characters
- Linear-clone visuals
- Material Design
- Inter font on white
- Pill badges in primary colors
- Bento grid hero
- Decorative gradient borders
- Floating-card soft-shadow layouts
- Generic SaaS template
- Stripe-clone visuals
- Anything that looks like Epic, PointClickCare, or MatrixCare — clinical EMRs are the visual register Haven competes against by NOT looking like them
- Anything that feels infantilizing — no smiley faces, no "Great job!" affirmations, no cartoonish empty states
- Anything that hides the gravity of the work — Haven documents real consequences and the UI should never undercut that
- Faux-warmth in operator surfaces — leave warmth for the family portal; admin surfaces are restrained
- Decorative use of color — color carries clinical meaning (red/amber/green) and must not be applied for aesthetic variety
- "Empower," "delight," "magic," "seamless" in copy — marketing language; Haven copy is plain, verb-led, specific
- Excessive use of icons in dense tables — icons compete with data; only use icons where they replace text, not where they decorate it
- Animated number counters on KPIs — animation suggests the number isn't trustworthy; Haven numbers appear in their final state
