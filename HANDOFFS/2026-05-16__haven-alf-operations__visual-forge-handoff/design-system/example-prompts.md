# Example Prompts

Use these as templates when commissioning the code agent to build surfaces in this project.

## Building the Dashboard

> Build the Haven ALF Operations dashboard. Follow the design system in /design-system/ strictly. Use the Surface Map rules for Dashboard. Apply the tokens via the Tailwind theme. It shows Assisted living executive directors running daily operations across census, care the metrics that matter most and the items needing attention. Use Stripe 40% · Mercury 30% · Linear 20% · Attio 10% weighting. Verify against the acceptance checklist before declaring done.

## Building the Inbox

> Build the Haven ALF Operations inbox. Triage queue with status dot + row hover + AI suggestion tag when appropriate. Use Linear 50% · Pylon 25% · Stripe 15% · Mercury 10% weighting. Keyboard-first. j/k to navigate, e to archive, ⌘K to search.

## Building the Critical Alert state

> Build the Haven ALF Operations critical alert state. Calm typography, unambiguous primary action. Use Linear 40% · Stripe 30% · Mercury 20% · Pylon 10% weighting. Never depend on color alone.
